# HeightMax

## Run the app

Run `npm run dev` to start the web app on port 5000. The Replit preview uses the `Start application` workflow.

## App behavior and limits

- The initial version is a dependency-free Node.js web app.
- Preferences, routine check-offs, daily check-ins, sleep logs, and height measurements are saved in this browser using local storage. They are not synced to an account or backed up online.
- Routine selection is simple preference-based logic; it is not an AI service or medical advice.
- Posture routines may support comfort and movement practice, but they do not promise changes in bone growth or height.
